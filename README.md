# Bitcoin Price Prediction

A machine learning project for predicting Bitcoin prices using historical market data and Python.

## 📌 Project Overview

Bitcoin prices are highly dynamic and can be influenced by various market factors. This project uses historical Bitcoin market data to analyze price patterns and build a machine learning-based prediction system.

The project includes data preprocessing, exploratory data analysis, machine learning model development, model storage, and a Streamlit web application.

## 🚀 Features

- 📊 Historical Bitcoin market data analysis
- 🧹 Data preprocessing and cleaning
- 📈 Data visualization
- 🤖 Machine learning-based Bitcoin price prediction
- 💾 Trained model storage
- 🌐 Interactive Streamlit web application
- 📓 Jupyter Notebook for analysis and experimentation

## 🛠️ Technologies Used
